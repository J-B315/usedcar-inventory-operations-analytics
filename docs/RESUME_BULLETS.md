# Resume Project Entry

## Used Vehicle Inventory & Operations Analytics | Power BI, Power Query, DAX, SQL

- Built an end-to-end Power BI solution for 185 vehicle inventory records, integrating inventory value, availability, operational readiness, data quality, and pricing review into a multi-page management dashboard.
- Cleaned and standardized inconsistent Excel data in Power Query, including vehicle parsing, mileage and price normalization, logical flags, anonymization, and reusable analytical segments.
- Designed a lightweight star-schema model with reusable make and salesperson dimensions and developed DAX measures for inventory, operations, pricing, and exception analysis.
- Created rule-based readiness, pricing-exception, and operational-priority logic to identify vehicles requiring management follow-up.
- Implemented field parameters, dynamic titles, synced slicers, bookmarks, conditional formatting, report-page tooltips, drill-through, and Performance Analyzer validation.
