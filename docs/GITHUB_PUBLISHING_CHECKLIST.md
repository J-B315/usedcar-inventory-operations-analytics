- [ ] Confirm you are permitted to publish the PBIX and its embedded data.
- [ ] Keep the original operational Excel workbook out of the repository.
- [ ] Confirm there are no full VINs, employee emails, customer data, Carfax URLs, or internal notes in the public model.
- [ ] Use `01_executive_overview.png` as the README hero image.
- [ ] Keep the three main dashboard screenshots in `screenshots/`.
- [ ] Upload `Vehicle_Inventory_Analytics.pbix` only if publication of the embedded data is approved.
- [ ] Otherwise, publish the PDF/screenshots and omit the PBIX from the public repository.
- [ ] Add the repository to the GitHub profile pinned repositories.
- [ ] Add the project to LinkedIn Featured after the repository is public.
