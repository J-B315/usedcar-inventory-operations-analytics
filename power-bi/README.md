# Power BI File

The interactive PBIX is intentionally not included in this public-safe package because PBIX files can contain embedded row-level data.

For a public GitHub portfolio, the dashboard PDF, screenshots, model documentation, DAX reference, and SQL files demonstrate the project without publishing the embedded operational dataset.

If you have explicit permission to publish the embedded data, add `Vehicle_Inventory_Analytics.pbix` to this folder from the private/full package.
