# Data Availability

The original operational workbook is intentionally **not included** in the public portfolio package.

The project was built from a real-world operational Excel workflow, but even after obvious identifiers are removed, row-level vehicle, price, workflow, and status data can still be commercially sensitive. For that reason, this repository includes the schema/data dictionary and analytical logic rather than the original source workbook.

The PBIX supplied by the project owner contains the embedded analytical model used to build the report. Before publishing the PBIX publicly, confirm that publishing the underlying business data is permitted.

See `DATA_DICTIONARY.md` for the public schema description.
