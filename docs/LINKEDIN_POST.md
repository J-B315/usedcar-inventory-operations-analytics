# LinkedIn Post Draft

I recently completed an end-to-end **Used Vehicle Inventory & Operations Analytics** project using Power BI, Power Query, DAX, SQL, and Excel.

The project started with a real-world operational workbook that contained inconsistent vehicle descriptions, mileage and price formats, workflow statuses, documentation fields, and sensitive identifiers. I transformed it into an analytical model and built an interactive report for inventory, operations, pricing, and exception review.

The final Power BI solution includes:

- Executive inventory KPIs and dynamic metric selection
- Operational readiness and data-quality monitoring
- Pricing vs. mileage analysis and make-level price benchmarks
- Pricing-exception flags and rule-based priority scoring
- Synced slicers, reset bookmarks, dynamic titles, tooltips, and vehicle drill-through
- Performance Analyzer validation before delivery

Snapshot metrics from the report include **185 vehicle records**, **45 available vehicles**, approximately **$2.34M in available inventory value**, and **117 vehicles requiring operational action**.

The biggest takeaway from this project was that a useful dashboard is not just a collection of visuals. The more important work was defining the data grain, cleaning inconsistent operational fields, creating business rules, structuring the model, and designing interactions that help a user move from an overview to a specific vehicle that needs attention.

**Tools:** Power BI | Power Query | DAX | SQL | Excel
